# PL/SQL Mail Maker ✉️

Uma ferramenta web prática para automatizar a criação de scripts PL/SQL de e-mails corporativos em lote.

## 💡 Motivação

Desenvolvi este projeto para otimizar uma demanda frequente no dia a dia, eliminando o trabalho manual e repetitivo na preparação e formatação de comunicados internos via banco de dados Oracle.

---
*Desenvolvido com HTML, Tailwind CSS e JavaScript.*
